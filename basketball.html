Open this link on the court TV (or any browser), tap once for fullscreen + buzzer. Huge score, clock, shot clock, fouls, timeouts and the same scoring pop-ups as OBS. Read-only.

BROWSER SOURCE LINK
  1. In OBS: Sources → + → Browser, paste the link.
  2. Width 1920, height 1080. Leave “Custom CSS” empty.
  3. Turn off “Refresh browser when scene becomes active”.
  4. Turn on “Control audio via OBS” for the buzzer.
  5. Keep this link private — it shows the graphics but can never change the score.
